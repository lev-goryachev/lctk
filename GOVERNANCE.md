# Governance

LCTK currently uses a benevolent-maintainer governance model.

The maintainer owns roadmap prioritization, architecture decisions, releases, repository configuration, security response, and final merge decisions. Durable architecture decisions are recorded as ADRs under `docs/adr/`.

External pull requests are not accepted during the pre-alpha foundation phase. The governance and review model will be revisited before contribution intake opens in roadmap Slice 1.5.

Project status and plans are communicated through repository documentation, GitHub Issues, and GitHub Discussions. No issue, discussion, or roadmap item is a delivery commitment.
