# Contributing

LCTK is public pre-alpha software. The project is not accepting external pull requests yet; contribution intake is planned for roadmap Slice 1.5.

Until then:

- use GitHub Issues for reproducible defects and focused feature requests;
- use GitHub Discussions for design questions and broader proposals;
- do not open pull requests unless a maintainer explicitly requests one;
- do not disclose suspected vulnerabilities in public issues or discussions—follow [SECURITY.md](SECURITY.md).

Opening an issue or discussion does not assign implementation work or guarantee acceptance. The maintainer may close proposals that conflict with the documented architecture or current roadmap.

Repository documentation, source comments, identifiers, diagnostics, and user-facing examples must be written in English. Architecture changes must update the relevant documents under `docs/` and include an ADR when they establish a durable decision.

When contribution intake opens, this document will be expanded with the development workflow, review policy, and contributor licensing terms.
