# Support

LCTK is pre-alpha software without production support guarantees.

- Use GitHub Discussions for setup and design questions.
- Use GitHub Issues for reproducible defects and focused feature requests.
- Use GitHub Private Vulnerability Reporting for security concerns, as described in [SECURITY.md](SECURITY.md).

Before reporting a problem, review the [documentation index](docs/index.md), [roadmap](docs/roadmap.md), and [open questions](docs/open-questions.md). Include the LCTK version or commit, operating system, architecture, Docker Desktop version, and minimal reproduction steps.
